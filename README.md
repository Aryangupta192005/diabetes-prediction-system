# Diabetes Prediction System

A Machine Learning project to predict the likelihood of diabetes using medical dataset features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## ML Models Used
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

## Features Used
- Glucose Level
- Blood Pressure
- BMI
- Age
- Insulin
- Other medical attributes

## Objective
To build a predictive machine learning model for diabetes detection and compare performance across multiple algorithms.

## Evaluation Metrics
- Accuracy Score
- ROC-AUC Score
